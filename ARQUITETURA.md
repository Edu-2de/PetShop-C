## ?? Tecnologias e Padrões

### Backend

#### Frameworks & Libraries
- **ASP.NET Core 8.0** - Framework web
- **Entity Framework Core** - ORM
- **AutoMapper** - Mapeamento objeto-objeto
- **Swashbuckle** - Documentação Swagger/OpenAPI

#### Padrões Utilizados
- **Repository Pattern** (implícito via EF Core)
- **DTO Pattern** - Separação de camadas
- **Dependency Injection** - Inversão de controle
- **RESTful API** - Padrão de endpoints
- **Async/Await** - Programação assíncrona

### Frontend

#### Frameworks & Libraries
- **Angular 17+** - Framework SPA
- **TypeScript** - Linguagem tipada
- **RxJS** - Programação reativa
- **HttpClient** - Requisições HTTP

#### Padrões Utilizados
- **Component-Based** - Arquitetura de componentes
- **Service Pattern** - Lógica de negócio
- **Observable Pattern** - Streams de dados
- **Dependency Injection** - Inversão de controle
